# Guess My Number - JavaScript DOM Project

A browser-based number guessing game built as my first DOM manipulation 
project while learning JavaScript with Jonas Schmedtmann on Udemy.

## About The Project

The player guesses a secret number between 1 and 20. The game tracks 
your score, saves your highscore, and can be reset without refreshing 
the page. All interactivity is handled through JavaScript DOM manipulation.

## How To Play

1. Enter a number between 1 and 20
2. Click Check to see if your guess is correct
3. The game tells you if your guess is too high or too low
4. Each wrong guess reduces your score by 1
5. Beat your highscore by guessing correctly with the highest score possible
6. Click Again to reset the game and try again

## What I Practiced

- Selecting and manipulating DOM elements with querySelector
- Handling user events with addEventListener
- Dynamically updating text content and styles via JavaScript
- Game logic with score and highscore tracking
- Writing reusable functions to keep code clean
- Using ternary operators inside DOM updates
